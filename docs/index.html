Cross-referencing Media Universe

A website for movie, series and book fans. Pick a title and see everything it is connected to: its sequels and remakes, the books it adapts, the rest of its universe and where to watch it.

  • 33 titles
  • 30 books
  • 76 actors
  • 11 platforms
  • 20 database tables

How it's built

  • Database: MySQL, with role subtypes, junction tables and recursive sequel and remake links
  • Backend: Node.js, Express and mysql2
  • Frontend: plain HTML, CSS and JavaScript
  • Logic in the database: a stored procedure for universe pages and a trigger that puts a new sequel in its parent's universe

Security

  • Passwords hashed with bcrypt
  • Placeholders in SQL queries to prevent SQL injection
  • Roles checked on the server for every protected request
  • A least-privilege MySQL account for the app
  • Generic error messages for visitors, with details only in the server log
